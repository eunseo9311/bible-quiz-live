# 성경 인물·지명 라이브 퀴즈

어르신과 발달장애 성도님을 위한 화면 안내형 성경 퀴즈입니다. 글을 읽거나 타자를 치지 않아도 큰 소리 한 번이면 함께할 수 있습니다. 파일 하나(`index.html`)로 동작합니다.

- 주소: https://eunseo9311.github.io/bible-quiz-live/
- 문제: 인물 20명과 지명 10곳, 모두 30문제입니다. 시작 화면에서 문제 묶음(전체·추수감사절·성탄절), 순서(차례대로·섞어서)를 고르고, 번호를 누르면 그 문제부터 시작합니다.
- 언어: 한국어, 中文, 日本語, English. 고른 언어로 화면 글씨가 바뀌고 음성 인식도 그 언어로 듣습니다.
- 흐름: 언덕 위 포털에서 인물이 걸어 나와 인사합니다. 단서와 힌트(한국어는 초성)가 나오고, 성도님들이 이름을 외치면 음성 인식으로 알아듣고 금빛 폭죽과 무지개 하트로 함께 기뻐합니다. 모세 문제에서는 홍해가 갈라집니다.
- 진행: 오른쪽 화살표, 스페이스바, 발표용 리모컨으로 다음 단계로 넘어갑니다. 왼쪽 화살표는 이전, `N`/`B`는 다음·이전 문제, `L`은 언어, `R`은 처음, `F`는 전체 화면, `M`은 소리입니다.
- 음성 인식은 크롬이나 엣지에서 잘 됩니다. 처음 한 번 마이크 사용을 허용해 주세요. 음성 인식에는 인터넷 연결이 필요합니다. 외친 이름을 못 알아들으면 오른쪽 화살표로 정답 화면을 열 수 있습니다.
- 주소 뒤에 `?lang=zh`, `?set=xmas`, `?q=5`, `?step=3`을 붙이면 언어, 묶음, 문제 번호, 단계를 정해서 시작합니다(리허설용).
- 문제를 고치거나 더하려면 `index.html` 스크립트 맨 위의 `QUIZ` 목록을 고칩니다.

다른 곳에 올릴 때는 `index.html`과 `og-image.jpg`를 같은 폴더에 두면 됩니다. 주소가 바뀌면 `index.html` 머리 부분의 `og:url`, `og:image` 값도 새 주소로 고쳐 주세요.
