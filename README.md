# 성경 인물 라이브 퀴즈

어르신과 발달장애 성도님을 위한 화면 안내형 성경 인물 퀴즈입니다. 글을 읽거나 타자를 치지 않아도 큰 소리 한 번이면 함께할 수 있습니다. 파일 하나(`index.html`)로 동작합니다.

- 주소: https://eunseo9311.github.io/bible-quiz-live/
- 흐름: 언덕 위 에메랄드빛 포털에서 모세가 걸어 나와 인사합니다. 지팡이를 들면 홍해가 솟아 갈라지고 초성 힌트(ㅁ ㅅ)가 나옵니다. 성도님들이 "모세!"를 외치면 음성 인식으로 알아듣고, 금빛 폭죽과 무지개 하트, 물기둥, 무지개로 함께 기뻐합니다.
- 진행: 오른쪽 화살표, 스페이스바, 발표용 리모컨으로 다음 단계로 넘어갑니다. 왼쪽 화살표는 이전, `R`은 처음, `F`는 전체 화면, `M`은 소리 켜기/끄기, `1`~`4`는 단계 이동입니다.
- 음성 인식은 크롬이나 엣지에서 잘 됩니다. 처음 한 번 마이크 사용을 허용해 주세요. 음성 인식에는 인터넷 연결이 필요합니다.
- 외친 이름을 못 알아들으면 오른쪽 화살표로 정답 화면을 열 수 있습니다.
- 주소 끝에 `?step=3`처럼 붙이면 그 단계부터 바로 시작합니다(리허설용).
- 호칭("권사님")이나 정답 문구는 `index.html` 스크립트 맨 위의 `CONFIG`에서 바꿉니다.

다른 곳에 올릴 때는 `index.html`과 `og-image.jpg`를 같은 폴더에 두면 됩니다. 주소가 바뀌면 `index.html` 머리 부분의 `og:url`, `og:image` 값도 새 주소로 고쳐 주세요.
